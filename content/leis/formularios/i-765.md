# I-765 — Application for Employment Authorization

Formulário para pedir o EAD (*Employment Authorization Document*, cartão de
autorização de trabalho). É usado por diferentes categorias elegíveis —
requerentes de asilo, ajuste de status (I-485) pendente, alguns dependentes
de visto de trabalho, entre outras — cada uma com sua própria categoria de
elegibilidade (código na própria petição, ex.: (c)(9) para I-485 pendente).

## Pontos-chave

- **A elegibilidade depende da categoria de base** — não existe pedido de
  EAD "solto", sem uma base elegível (visto, ajuste pendente, asilo, etc.).
- **Validade determinada por categoria** — algumas categorias têm EAD válido
  por período fixo, com necessidade de renovação; outras acompanham a
  validade do status de base.
- **Trabalhar sem EAD válido**, quando exigido pela categoria, é violação de
  status — mesmo com outro pedido (como I-485) pendente.
- **Extensão automática de validade (8 CFR §274a.13(d))** — para algumas
  categorias de renovação específicas, o USCIS reconhece uma extensão
  automática do EAD vencido por um período determinado enquanto a renovação
  está pendente, desde que os requisitos da regra sejam atendidos. Não é
  universal — depende da categoria e de protocolo tempestivo da renovação;
  confirmar a categoria específica antes de presumir a extensão.
- Taxa: conferir sempre valores atuais no site do USCIS — mudam.

## ⚠️ Nova edição obrigatória a partir de 15/09/2026 (sem período de tolerância)
O USCIS publicou a edição **09/15/26** do I-765 junto com o I-539, para
implementar a regra final "Fixed Time Period of Admission" (fim do D/S para
F-1/J-1/mídia estrangeira). Não há grace period:
- **Antes de 15/09/2026:** só a edição 08/21/25 é aceita.
- **A partir de 15/09/2026:** só a edição 09/15/26 é aceita.
Fonte: https://www.uscis.gov/newsroom/alerts/uscis-to-publish-new-editions-of-form-i-539-and-form-i-765-older-editions-will-be-rejected-starting

## Limites de uso neste app

- Nunca afirmar que uma categoria específica de EAD está automaticamente
  disponível sem confirmar a base elegível do caso.
- Prazos de processamento variam muito por categoria — nunca hardcodar um
  número fixo; apontar para o Case Processing Times oficial.
